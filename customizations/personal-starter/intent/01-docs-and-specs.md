# Personal Blueprint — 01 Editorial & Specifications

## 1. Scope & Tiers
Covers academic monographs, executive decision memos, engineering protocol specifications, and operational playbooks:
- **01. Doc-1 (Scientific Monograph):** Strict 2-column academic layout with margin sidenotes, math formulas, and serif narrative prose.
- **02. Doc-2 (Executive Decision Memo):** Structured Bottom Line Up Front (`BLUF`), trade-off tables, and embedded Mermaid architectural state charts.
- **03. Doc-3 (Normative RFC Specification):** Protocol definitions with `MUST`/`SHALL` compliance criteria and finite-state machine diagrams.
- **04. Doc-4B (API & SDK Reference):** Encyclopedic function indices, 6-stage flow spine (`.va-flow-spine`), and decision tables.
- **05. Doc-4A (Operational Runbook):** Split-pane execution workflows pairing narrative instructions with code panes.
- **06. Bridge-1 (Parametric Worksheet):** Interactive scientific calculations and trade-study sliders.

## 2. Typographic Rules
Long-form body copy in `Doc-1` utilizes `--font-serif` (`Newsreader`/`Charter`), while headings, kickers, and code snippets remain strictly aligned to `--font-sans` and `--font-mono`.
