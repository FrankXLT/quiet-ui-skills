# Personal Blueprint — 02 Workspaces & Applications

## 1. Scope & Tiers
Organizes daily productivity, life pacing, telemetry tracking, and software architecture:
- **07. Deck-1 (Briefing Stage):** Viewport-locked `100dvh` assertion slides for high-impact visual presentations.
- **08. Bridge-2 (High-Density Fleet Ledger):** Tabular fleet inventory with 3-zone cards (`.va-fleet-card-3zone`) and bulk action bars.
- **09. App-2 (Metrics & Time-Series Console):** Real-time signal waveforms, strip charts, and hardware telemetry.
- **10. App-1 (Issue & Task Tracker):** Compact 36px triage rows with live inspector drawer.
- **11. App-4 (Task & Calendar Planner):** Focused daily execution featuring daily briefings, priority rings, and time blocks.
- **12. App-3 (Bento KPI Dashboard):** Balanced 2x2 executive matrix with expected-pace bars and threshold gauges.
- **13. App-5 (Wellness & Restorative Companion):** Daily circadian pacing, sleep readiness rings, and state hypnograms.
- **14. App-Tree (Hierarchical Tree & Schema Explorer):** 3-pane schema explorer with synchronized query workbenches.

## 2. Invariants
All data grids enforce `tabular-nums` alignment, and nested cards maintain concentric curvature with `--radius-inner`.
