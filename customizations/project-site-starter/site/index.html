OPEN PROJECT PORTAL

Ship clear documentation and project overviews without frontend build bloat.

Open Workbench Starter gives maintainers a clean static site with a focused overview page, a two-column Markdown docs reader, and shared navigation across sibling tools.

>open-workbench_ >oaw-site.json_ >docs-reader_
Get Started Browse Repository

1 — Copy Starter Folder

Duplicate this starter folder once and fill in your spelled-out project title and Markdown guides.

2 — Build Static Routes

Compile Overview, Docs, and your 1280x640 preview image with zero JavaScript build steps.

3 — Ship Anywhere

Publish static HTML, CSS tokens, and vector diagrams to GitHub Pages or any web host.

Quick Install

Copy and run locally

Build static site

python3 -B customizations/scripts/build_project_site.py --config oaw-site.json --out dist

Key Capabilities

One Manifest, Predictable Routes

Keep project metadata, sibling switcher links, and navigation routes in a single validated JSON manifest with zero hidden build config.

Plain Markdown Documentation

Write guides in ordinary Markdown files and render them into a fast, keyboard-accessible reader with section links and quick jumps.

Offline-Ready Static Output

Emit self-contained HTML, CSS, and vector diagrams that deploy cleanly to any static host across four readable light and dark themes.

Architecture

How a single manifest and Markdown guides compile into static HTML, CSS tokens, and social preview cards.
