# Brand Blueprint — 00 Global Structure

## 1. Intent & Identity
The Brand Starter provides a clean, enterprise-grade design framework tailored for team products, SaaS applications, developer portals, and corporate engineering hubs. It focuses on the 13 core product tiers, omitting personal wellness trackers and residential smart-home interfaces.

## 2. Navigation Architecture
- **N0 (Zero-Chrome):** Focused documentation reading for executive whitepapers and RFC specifications.
- **N1 (Left Rail):** Standard corporate workspace navigation for ticket triage, sprint planning, and schema tools.
- **N2 (Sub-Header Tabs):** Contextual tab bars for high-density fleet ledgers and multi-channel telemetry.
- **N3 (Dual-Rail Spine):** Comprehensive API references with 6-stage flow spines.
- **N4 (Responsive Bottom Bar):** Mobile viewports automatically adapt to bottom thumb bars on screens <= 640px.

## 3. Brand Invariants
- **Color Consistency:** Primary corporate accent (`#2563EB`) paired with secondary focal teal (`#0D9488`).
- **WCAG AA Compliance:** Text contrast ratios strictly maintain >= 4.5:1 against surface tokens.
- **Concentric Geometry:** Radius math guarantees nested containers preserve optical balance.
