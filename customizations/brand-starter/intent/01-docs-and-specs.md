# Brand Blueprint — 01 Editorial & Specifications

## 1. Scope & Tiers
Delivers technical and architectural documentation across 6 core editorial archetypes:
- **01. Doc-1 (Whitepaper & Monograph):** Multi-column technical specifications with margin notes and mathematical proofs.
- **02. Doc-2 (Decision Memo):** Executive strategy memos with structured BLUF headers and trade-off tables.
- **03. Doc-3 (Normative RFC Specification):** Standard protocol definitions with formal compliance terminology.
- **04. Doc-4B (Developer SDK Reference):** Encyclopedic API references with dual-rail navigation and interactive flow spines.
- **05. Doc-4A (SOP & Incident Runbook):** Split-pane operational workflows pairing procedural guidance with terminal code blocks.
- **06. Bridge-1 (Parametric Worksheet):** Engineering trade-study worksheets with real-time parametric sliders.

## 2. Invariants
All code samples use `--font-mono`, while documentation kickers and headings enforce unified `--font-sans` styling.
